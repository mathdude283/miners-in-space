# Moonbound

A free educational space game for NASA Space Apps 2026, inspired by NASA's Artemis II. Moonbound is fiction. NASA does not endorse it.

**Watch the 30-second demo:** [docs/Moonbound-demo-30s.mp4](docs/Moonbound-demo-30s.mp4)

## What you do
- **Contracts 01 to 03 (the Moon):** choose a crew, build one ship, run the launch poll and countdown, fly the climb, photograph the real Orientale Basin from NASA's own far-side picture, compare craters under different light, and work out what you can honestly conclude when only some windows saw a flash. Get a grade, points and badges, and a quiz from Mission Control.
- **Contracts 04 to 06 (spacecraft design):** design an uncrewed spacecraft for Earth wildfire, lunar ice or Neptune from real part numbers, pick its orbit, run its mission, and learn why each choice worked.
- Every fact is labelled REAL (with its source) or GAME (a game rule). See [SOURCES.md](SOURCES.md).

## Run it
- **Windows build:** ask the team for `Moonbound-Windows.zip` (one `Moonbound.exe`, no install).
- **From source:** install Godot 4.7, open this folder as a project and press Play.
- **Tests:** `powershell -ExecutionPolicy Bypass -File tests\run_tests.ps1`
